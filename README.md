# EndNote GB/T 7714 citation skill

A Codex skill for replacing a document's existing citations with live EndNote Cite While You Write fields and generating a GB/T 7714 bibliography.

## Install

Copy the `endnote-gb7714-citations` folder into your Codex skills directory (`$CODEX_HOME/skills`, or `~/.codex/skills` when `CODEX_HOME` is unset). Then start a new Codex task and ask it to use `endnote-gb7714-citations`.

The skill expects Microsoft Word with EndNote Cite While You Write when live, editable EndNote citations are required. It does not include or upload any document or EndNote library.
